authorizeMultiIssuer

open fun authorizeMultiIssuer(tokens: Map<String, String>, action: String, resource: JSONObject, context: JSONObject): MultiIssuerAuthorizeResult

Authorize using JWT tokens from multiple issuers.

This is the recommended replacement for the removed authorize(Map&lt;String,String&gt;, ...) method. Each map entry is a token mapping name (e.g. "Jans::Access_Token") to the raw JWT string.

Return

authorization result

Parameters

tokens

mapping name → JWT string (must not be null; no null keys or values)

action

Cedar action (e.g. "Jans::Action::\"Read\"")

resource

resource as JSONObject (must not be null)

context

context as JSONObject (may be null; sent as empty JSON object to the engine)
